# TaskMaster - Python CLI To-Do Manager

A clean and lightweight command-line interface (CLI) to-do list manager built with Python. Tasks are automatically saved to a local JSON file so your progress persists across sessions.

## Features
- **Add Tasks:** Quickly record pending todos.
- **Track Status:** Mark items as completed or pending.
- **Delete Tasks:** Remove unwanted entries.
- **Auto-Save:** Saves data automatically in `tasks.json`.
